# ADR-XXXX: 짧은 결정 제목

## 문제와 배경

무엇을 결정해야 하며 왜 지금 결정해야 하는가?

## 결정 기준

- 가장 중요한 품질 또는 제약
- 운영 복잡도, 정합성, 비용, 성능, 팀 역량 등

## 고려한 선택지

1. 선택지 A
2. 선택지 B
3. 아무것도 바꾸지 않음

## 선택

선택한 안을 한두 문장으로 명확하게 적습니다.

## 선택 이유

- 결정 기준과 연결해 설명합니다.
- 당시의 사실과 가정을 구분합니다.

## 포기한 이유

### 선택지 A

현재 조건에서 선택하지 않은 이유를 적습니다.

### 선택지 B

어떤 조건이 되면 다시 유효한 선택지가 되는지도 적습니다.

## 결과와 감수한 단점

- 얻는 것
- 의도적으로 감수한 복잡도와 제약

## 운영 시 고려사항

- 관측할 지표와 로그
- 장애와 복구 절차
- 배포와 롤백
- 보안, 비용, 데이터 보정, 소유권

## 검증 방법

- 테스트, 리뷰, 모니터링 등 결정 준수 여부를 확인하는 방법

## 재검토 조건

- 이 결정을 다시 열어야 하는 구체적인 조건

## 근거와 관련 자료
