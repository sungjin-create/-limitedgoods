# ADR-0002: 재고와 구매 제한을 주문 transaction에서 원자적으로 예약

- 상태: accepted

## 문제

애플리케이션에서 재고를 읽고 차감하면 동시 요청이 같은 재고를 보고 초과 판매할 수 있습니다. 주문별 제한만 검사하면 여러 주문으로 누적 한도를 넘을 수 있습니다.

## 결정

재고는 조건부 update로 차감하고, 사용자·상품별 구매 수량은 `user_product_purchase_counter`의 `ON CONFLICT ... WHERE`로 예약합니다. 주문과 두 예약은 같은 transaction에 참여합니다.

## 결과

경합 중 하나의 조건이라도 실패하면 전체 주문이 rollback됩니다. 만료·환불 경로는 예약 또는 결제 수량을 정확히 한 번 복구해야 합니다.
