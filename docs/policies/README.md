## 공통 원칙

- 서버의 PostgreSQL 재고와 주문 상태가 최종 기준입니다.
- 시간 비교는 서버의 `LocalDateTime.now()`와 DB `current_timestamp`를 사용합니다.
- 고객 요청의 JWT 사용자와 path/body의 리소스 소유권을 함께 확인합니다.
- 중요한 상태 변화는 이력과 Outbox 이벤트를 기록합니다.
- 비동기 통계·메일은 원본 상태보다 늦게 반영될 수 있습니다.

정책 값이나 상태 enum을 바꾸면 이 문서, API 문서, Flyway 제약 조건과 화면 문구를
함께 갱신합니다.
